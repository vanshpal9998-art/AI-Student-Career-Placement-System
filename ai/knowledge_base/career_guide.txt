GENERAL PLACEMENT GUIDE
=======================

Resume:

* Keep your resume clear and concise.
* Use a professional email address.
* Mention relevant technical skills.
* Add meaningful academic or personal projects.
* Explain your contribution to each project.
* Keep education details accurate.
* Check spelling and grammar.
* Customize your resume for the target role.

Interview:

* Prepare a short self-introduction.
* Understand every project on your resume.
* Practice technical questions.
* Practice coding problems.
* Prepare HR questions.
* Research the company before an interview.
* Explain your problem-solving approach.
* Be honest when you do not know an answer.

Technical Preparation:

* Practice programming regularly.
* Learn data structures and algorithms.
* Understand databases and SQL.
* Learn Git and GitHub.
* Build real projects.
* Practice debugging.
* Improve communication skills.

Projects:
Students should build projects that demonstrate their skills.
A good project should have:

* Clear problem statement
* Useful features
* Database
* User interface
* Error handling
* Documentation
* GitHub repository

Placement Preparation:

1. Choose a target career.
2. Identify required skills.
3. Compare current skills with required skills.
4. Learn missing skills.
5. Build projects.
6. Improve resume.
7. Practice interviews.
8. Apply for suitable jobs.
9. Track applications.
10. Continue learning.

AI ASSISTANT RESPONSE GUIDELINES
================================

When a student asks about a career:

* Explain the career.
* List important skills.
* Suggest a learning path.
* Suggest project ideas.

When a student asks what to learn:

* Check their preferred career.
* Check their existing skills.
* Identify missing skills.
* Suggest beginner, intermediate and advanced topics.

When a student asks about placement:

* Give practical preparation steps.
* Suggest resume improvements.
* Suggest interview preparation.
* Suggest relevant projects.

When a student asks about interviews:

* Provide technical preparation.
* Provide HR preparation.
* Suggest practice questions.
* Give communication tips.

When a student asks about their career:

* Use their profile information.
* Consider skills, interests and preferred career.
* Provide personalized learning suggestions.
